# 実装計画 — そらへ（モノと思い出を手放すためのWebアプリ）

このタスクリストは requirements.md / design.md に基づく。
現行実装（v1.4.0）で完了済みの項目は [x]、将来対応は [ ] で示す。

## 完了済み（v1.4.0）

- [x] 1. 静的サイトの土台を作成する
  - `index.html` / `styles.css` / `app.js` の3ファイル構成を用意
  - Google Fonts（Shippori Mincho / Zen Kaku Gothic New）を読み込む
  - _要件: 10.1, 10.2_

- [x] 2. 画面骨格とタブ切り替えを実装する
  - ヘッダー、2つのタブ、2つのフォームパネル、フッター、演出オーバーレイを配置
  - `data-tab` に応じたパネル表示切替と選択状態の視覚化
  - _要件: 1.1, 1.2, 1.3, 1.4_

- [x] 3. モノの入力フォームを実装する
  - 写真アップロード領域（クリック / ドラッグ&ドロップ）とプレビュー
  - 名前欄（40字）・メッセージ欄（300字）と文字数制限
  - 画像以外のファイルを無視する
  - _要件: 2.1, 2.2, 2.3, 2.4, 2.5, 2.7_

- [x] 4. 思い出の入力フォームを実装する
  - タイトル欄（40字）と思い出テキスト欄（600字）
  - _要件: 3.1, 3.3_

- [x] 5. 入力バリデーションを実装する
  - 写真未選択の送信時にアップロード領域を警告表示
  - 思い出テキスト未入力の送信時にテキスト欄を警告表示
  - _要件: 2.6, 3.2_

- [x] 6. お別れメッセージ生成（モック）を実装する
  - モノ用・思い出用の定型文配列を用意
  - メッセージ有無・名前・思い出の長さに応じた文面選択
  - 名前の差し込み
  - _要件: 6.4, 6.5, 6.6_

- [x] 7. 供養アニメーションの基盤を Canvas 2D で実装する
  - `Particle` クラス（位置・色・寿命・光暈・上昇/揺らぎ）
  - `requestAnimationFrame` による描画ループ
  - p5.js 依存を排除
  - _要件: 4.1, 5.1_

- [x] 8. 写真の粒化を実装する
  - オフスクリーン canvas と `getImageData` によるピクセル抽出
  - 一定間隔サンプリングと `yNorm` 付与
  - _要件: 4.4_

- [x] 9. HOLD フェーズ（写真を見せる）を実装する
  - 開始直後に元写真を静止表示し、終盤でそっと薄れさせる
  - _要件: 4.2, 4.3_

- [x] 10. 上昇フェーズと暖色演出を実装する
  - 下部の粒から順に発ち、ゆっくり上昇・フェードアウト
  - 暖色（オレンジ〜金）の光暈、芯は写真色を保持（白飛び防止）
  - 通常速度で約8秒のゆったりした尺
  - _要件: 4.5, 4.6, 4.7, 4.8_

- [x] 11. 思い出モードの光の粒を実装する
  - 中央付近に暖色主体の光の粒を配置し上昇させる（粒0件フォールバック兼用）
  - _要件: 5.2, 5.3_

- [x] 12. お別れメッセージ表示を実装する
  - 差出人ラベル表示、本文の一文字ずつの表示
  - 粒がおおむね還る/規定時間経過での表示条件
  - 進まない場合のフォールバックタイマー
  - _要件: 6.1, 6.2, 6.3, 6.7_

- [x] 13. 演出の操作を実装する
  - 速度スライダーによるリアルタイム速度変更
  - 閉じるボタンでオーバーレイを閉じ、フォームを初期化
  - _要件: 7.1, 7.2, 7.3, 7.4_

- [x] 14. プライバシー表記とバージョン表示を実装する
  - データを送信・保存しない設計と、その旨の画面明示
  - 左下のバージョンバッジ
